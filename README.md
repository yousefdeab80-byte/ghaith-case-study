## التقنيات

Next.js 15 (React 19) + Tailwind، وقاعدة بيانات PostgreSQL (Supabase) عن طريق Drizzle ORM، واستضافة على Vercel.

## التشغيل على جهازك

```bash
npm install
cp .env.example .env.local      # وعدّل DATABASE_URL و SESSION_SECRET
npm run db:migrate              # إنشاء الجداول
npm run db:seed                 # المشروعات الافتراضية وحساب المدير (admin)
npm run dev                     # http://localhost:3000
```

كلمة مرور حساب `admin` الأولى هي قيمة `SEED_ADMIN_PASSWORD` (أو `Ghaith@2026` لو مش محددة). غيّرها أول ما تدخل من صفحة حسابي.

## النشر (Supabase + Vercel)

1. اعمل مشروع جديد على [Supabase](https://supabase.com)، وخد رابط الاتصال من
   Project Settings ← Database ← Connection string ← **Transaction pooler** (بيبدأ بـ `postgresql://` وفيه البورت 6543).
2. على [Vercel](https://vercel.com) اعمل Import للريبو ده، وضيف المتغيرات:
   - `DATABASE_URL`: رابط Supabase من الخطوة 1
   - `SESSION_SECRET`: نص عشوائي طويل (40 حرف أو أكتر)
   - `SEED_ADMIN_PASSWORD`: كلمة مرور المدير الأولى
3. Vercel بيشغّل `vercel-build` اللي بيعمل الجداول والبيانات الأساسية قبل البناء، فمش محتاج تعمل حاجة يدوي.
